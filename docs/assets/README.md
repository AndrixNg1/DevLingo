# Demo assets

Public Marketplace captures belong in `assets/marketplace/` at the repository root. Four real PNG screenshots are already present there and are included in the VSIX. This contributor-only directory is excluded from packaging.

No demo GIF or raw video is bundled. Follow [the demo script](../demo-script.md) before adding `assets/marketplace/devlingo-demo.gif`; never include credentials, personal information or private source content. See [Marketplace readiness](../marketplace.md) for the remaining HTTPS image-hosting check.
