# Roadmap

DevLingo is currently an alpha extension. This roadmap describes direction, not dated delivery commitments.

## Completed

- Core provider-independent translation architecture
- Selected-text translation and comment translation on hover
- Markdown file translation with protected syntax/content
- OpenAI, DeepL and Google Cloud Translation Basic v2 providers
- Secure credentials through VS Code SecretStorage
- Provider selector and provider-isolated translation caches
- Native command center, editor toolbar and context menus
- Automated lint, compile and offline tests
- VSIX packaging and installed-extension testing, validated by the maintainer
- Removal of the development Mock provider; test fixtures remain offline

## Current phase

- Open-source documentation, contributor guides and GitHub templates
- Security reporting and licensing readiness
- Real demonstration preparation

## Next

- UX polish and alpha stabilization
- Review Markdown and language edge cases
- Real demo and Marketplace visual assets
- Configure private security and conduct reporting channels
- Marketplace publication after readiness review

## Stable milestone: DevLingo v1.0.0

A reviewed, documented release with validated installed-extension behavior, contributor guidance, security reporting and Marketplace readiness. No date is promised. New providers may be proposed through issues; no additional provider is currently committed here.
